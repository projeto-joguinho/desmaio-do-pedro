# O Desmaio do Pedro

Escape room de bioquímica em voxel para o ensino médio. A jogadora é a enfermeira de plantão e precisa descobrir por que o Pedro, 16 anos, desmaiou na aula de Educação Física, passando por 4 estações: triagem, nutrição, hormônios e energia da célula.

Para jogar, abra `index.html` no navegador (computador ou celular).
